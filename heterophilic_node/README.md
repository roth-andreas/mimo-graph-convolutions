# What can we learn from MIMO graph convolutions?
This implementation is based on the paper "Where Did the Gap Go? Reassessing the Long-Range Graph Benchmark" and its implementation https://github.com/toenshoff/LRGB, which is based on https://github.com/rampasek/GraphGPS


### Running Training
The full grid search can be executed with the following script:
```bash
conda activate graphgps
zsh run.sh
```
